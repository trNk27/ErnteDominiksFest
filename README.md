# 🌳 ErnteDominiksFest

Ein satirisches Baum-Farming-Spiel: Kommandiere **Manni**, **Jannes** und **Benni** über
den Acker, züchte Bäume, an denen pralle **Dominiks** reifen, und verkaufe sie am
Feststand — bevor sie matschig werden oder die Blattläuse zuschlagen.

**Spielen:** Einfach `index.html` im Browser öffnen (oder via GitHub Pages hosten).
Keine Installation, kein Build, läuft auf Handy und Desktop.

**Steuerung:** Arbeiter antippen → Baum/Brunnen/Feststand antippen → Aufgabe wählen.
Die Warteschlange oben zeigt alle Aufträge; Antippen bricht sie ab.

**Ziel:** 300 € Festkasse bis zum Ende von Tag 10 — sonst fällt das Fest aus. 😢
