# 🌳 ErnteDominiksFest

Ein satirisches Baum-Farming-Spiel in der Ich-Perspektive: Du allein läufst über den
Acker, züchtest Bäume, an denen pralle **Dominiks** reifen, und verkaufst sie am
Feststand — bevor sie matschig werden oder die Blattläuse zuschlagen.

**Spielen:** Einfach `index.html` im Browser öffnen (oder via GitHub Pages hosten).
Keine Installation, kein Build, läuft auf Handy (Querformat) und Desktop.

**Steuerung:** Links bewegen (virtueller Joystick bzw. WASD/Pfeiltasten), rechts
umsehen (Drag bzw. Q/E). Lauf mit dem Fadenkreuz auf einen Baum, den Brunnen, den
Feststand oder den Laden zu und drück den ✋-Aktion-Button (oder tippe kurz aufs
Spielfeld), um zu handeln.

**Ziel:** 300 € Festkasse bis zum Ende von Tag 10 — sonst fällt das Fest aus. 😢
